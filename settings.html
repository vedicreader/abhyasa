settings

One table for each value that you can change, and the file that keeps your changes.

Each value that a person can change is a row in one table, SETTINGS. A row has a group, a name, a label, one line of help, a type, a default and, for a number, a range. The engine, the web app and the Settings page all read this table. Thus each value has one place.

Your changes go in settings.json in cfg_dir(). The code reads a value when it uses it, so a change works at once, with no restart. A saved value outside its range gets the nearest end of the range. A saved value of the wrong type gets the default. A bad file never stops the app.

This module imports only the standard library and fastcore. Each engine module reads its values from here, so the import must stay light.

The groups

The Settings page shows the groups in this order. Each group has a label and one lead line.

The table

add puts one row in SETTINGS. The name is section.key: the section of settings.json and the key in it. The type comes from the default. more puts the row under the closed “More” part of its group. store='profile' marks a value that the vault keeps in your profile, not this file. hi can be the name of another row. Then that value is the top of the range. ui=False marks a value that its group shows with its own controls. reset=False keeps a value when you use the defaults of its group: the theme, and the speech engine and model.

Add the setting name to SETTINGS and return its row.

The Look group keeps its own controls: the theme swatches and the mode. The Learning group holds the three values of your profile.

The Walks group sets the size of a walk and of a side walk.

The Talks group sets how a talk runs: the questions, the time, the vote and the room.

The Checks and grading group sets the tries, the grade of a shaky pass, and when an idea counts as learned.

The Review group sets the time to the next review. A daily limit on review is new: 0 means no limit, as before.

The Links group sets how much of a link the tutor gets. The pages read by default can not be more than the page cap.

The Research group sets the web search for a step with no source. The tutor searches the web for the idea, reads the best pages, and quotes one passage word for word. When research is off, the tutor does no web search, and the step says that the text is in the tutor’s words.

The Speech to text group keeps the engine and the model, and the pauses at which the mic cuts what you say. The Screen guide group has the voice and the look of a point mark. A point mark is weaker than a circle in each look, so a circle is always the main mark of a step. The default is tick, because it has no ring that looks like a circle.

The Speaking voice group picks who reads the steps of the screen guide aloud. pocket runs Pocket TTS on this Mac. openai sends each line to OpenAI. browser is the voice of the browser (or of the Mac in the overlay). The voice module reads these values. The default is pocket. Until its model is downloaded, the browser speaks. A value from before 0.0.16 (kokoro or hf) is not one of the choices, so it reads as pocket. The speed is only for OpenAI: Pocket TTS has no speed.

The Models group has the default model and one model for each task. An empty value uses the default model. The tasks after extract borrow the model of an older task when they have none: BORROWS says which. The screen guide (guide) and its figure labels (guide_vision) use the model for hints until you pick one. The reply caps are in tokens.

The Lists group sets how many items show in the lists of the app. All of it is under “More”.

Each group except Prompts has rows, and each row is in a group. The Prompts group lists the prompts of prompts.PROMPTS.

assert set(GROUPS) - {'prompts'} == {r.group for r in SETTINGS.values()}
assert all(r.kind != 'int' or r.lo <= r.dflt for r in SETTINGS.values())
len(SETTINGS)

The file

DFLT_SETTINGS is the default of each section: the rows that the file keeps, the saved prompt texts and the models that the Settings page downloaded. settings() gives the saved settings over the defaults. A section that is not a dict in the file is ignored, and a top-level key that is not known is dropped.

Read one value

fit makes a saved value fit its row. A number outside the range gets the nearest end. A value of the wrong type gets the default. A whole number can come as 12.0 from a form; it stays a whole number. A choice must be one of the choices.

sources.roots is a text list, one path for each line. A source folder has the same rules as a folder that you name: it must be in your home folder, it must not be the home folder itself, and no part of it can be hidden or a link. source_root_why gives the reason when a path breaks a rule. roots gives the paths that keep the rules, and dropped_roots gives the others with their reasons, so the Settings page can show them.

Change one value

The source folders drop the root of the disk, the home folder itself and a hidden folder.

A value saved out of range is saved as the end of the range. reset and reset_group put back the defaults.

What stays fixed

Some values keep you safe, so they have no setting: the link checks for local addresses, plain HTTP, the link kinds, the HTML allowlist, the check of a pane address, the local-only hosts, the test allowlist, the grade scale and the depth ladder. The room for phones keeps its safety limits fixed too: the bind rule, the join code, the rate limits, the body size and the headers. FIXED names them, and no row may have one of these words in its name.

assert not [n for n in SETTINGS for w in FIXED if w in n]
